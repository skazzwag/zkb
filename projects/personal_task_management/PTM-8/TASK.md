**Issue Number:** 8

**Description:**
To make best use of opencode for agent-focused development I want subagent system where each subagent owns a different part of the data stack. These subagents will be based off of standard data roles. Data Architect will be for system design decisions, data engineer will be for ingestion, orchstration and devops/gitops, analytics engineer will be for transformations and context engineering, and data analyst will be for investigating data problems and dashboarding. These wil be triggered using a data product owner major mode where I give details on what I want opencode to make.
